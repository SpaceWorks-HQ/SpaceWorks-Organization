# Design

Space Works Organization follows the **Space Works brand** and **Space Works UX**, both from
[SpaceWorks-Design](https://github.com/SpaceWorks-HQ/SpaceWorks-Design):

- **Brand:** `tokens/tokens.css` and `docs/ui-brand-spec.md` set colour, type, logo and voice.
- **UX:** `docs/ux-spec.md` sets patterns P1–P30, layouts L1–L10 and the quality bar. Space Works UX was inspired by Yuyu.

## Where things live

| File | What it is |
|---|---|
| `app/styles/tokens.css` | The kit's tokens re-emitted as `--sw-*`, generated by `npm run design:sync`. **Never edit by hand.** |
| `app/styles/semantic.css` | Role names (canvas, panel, ink, primary, status pills…) pointing at kit tokens, in light and dark. |
| `app/globals.css` | The Tailwind 4 theme mapped onto the roles, fonts, type scale and motion. |
| `public/brand/` | Fonts, logo masters and icons copied unaltered from the kit. `brand/SOURCE.json` records the commit. |
| `components/ui/*` | Primitives: button, field, select, choice, dialog, menu, tabs, table, display. |
| `components/brand/*` | Logo, loader and mood tiles. |

To update from the kit: `npm run design:sync` (it reads `../SpaceWorks-Design`, or a path you pass in), then
run the tests.

## Decisions

- **Colour mode.**
  - Light is the default. Choosing dark puts the class `dark` on `<html>`, rendered on the server from the
    `swo.theme` cookie, so there is no flash.
  - There is no System option, and `prefers-color-scheme` is never consulted.
- **Palette.**
  - `@theme { --color-*: initial }` removes Tailwind's default palette. The only colours available are the kit
    roles, plus `white`/`black`, which exist only for colour-picker handles and scrims.
- **Type.**
  - **Gilroy Light (300)** for all reading and interface text.
  - **Gilroy ExtraBold (800)** for headings and emphasis. The Light face answers weights 100–549 and ExtraBold
    answers 550–900, so `font-medium` renders Light and `font-semibold`/`font-bold` render ExtraBold, and
    nothing is synthesised.
  - **Unbounded** is for one accent phrase per public layout, never in staff chrome.
  - Body copy is 16px minimum (14px only for labels and captions), because Light is a thin face.
  - Licence: only the free Gilroy release (Radomir Tinkov Free Font EULA) ships. The converted 400–700 weights
    are never used.
- **Shape.**
  - Controls are **pills** (`--radius-control: 9999px`, owner decision J1). That covers buttons, single-line
    inputs, selects and nav items.
  - Multi-line fields and cards use 16px, and tags are fully round.
  - No card shadows. Only overlays float (`shadow-float`).
- **Accent.** Teal by default. Public organisation pages may set their own with `accentStyle()` on a
  `.sw-accent-scope` root. Every derived value is contrast-checked to AA.
- **Shell dimensions.**
  - Sidebar 256px. Nav items 44px tall.
  - Content max width 1120. Gutters 16/24/36.
  - Breakpoints: 640/768/1024/1280. Below 1024 the shell becomes a top bar plus a sheet.
  - There is no icon rail, because the nav is text-only (D9).
  - At most two sidebar count badges.
- **Motion.**
  - Durations: colour 120ms, expand 200ms, overlays 240ms in and 160ms out.
  - Easing `ease-sw`.
  - No hover lift.
  - Reduced motion is respected.
- **Copy.** Sentence case, en-GB, and buttons named after their action. No "Oops", and no exclamation marks
  on errors.

## Landing page (`/`)

The marketing home follows one sample member, Shaan Shoukath of SpaceWorks, through a membership year,
April to March. It shares its vocabulary with the sister Space Works site:

- **Grounds.** Warm Cream sections with the faint isometric box pattern (authored SVG, masked to the edges),
  a full-bleed Deep Ink band for money and a Maker Teal band for self-hosting.
- **Type.** Two-line Gilroy ExtraBold headlines ending in full stops. The page's one Unbounded phrase is
  "One card." in the year section.
- **Action.** Workshop Orange (`highlight` button) is used only for "Apply for your organisation".
- **Objects.** Member card, receipt slip, reminder note, proof chips and terminal are flat brand objects.
  Every one is labelled as a sample; the page makes no customer or usage claims.
- **Motion** (all in `components/marketing/landing.css`, all still under reduced motion). Scroll-driven reveals (`.sr-*`) give each section its own entrance: the hero deck fans apart as it leaves, headings rise, timeline rows arrive from the left, panels lift, report bars grow and the terminal slides in. Load and interaction motion:
  - The hero fills the first screen; its headline lines slide up and the deck is dealt once.
  - The card flips to its QR side on demand.
  - A strip of sample cards slides past under the hero and pauses on hover, focus or its button.
  - The year ruler fills as the section scrolls.
  - The receipt prints once and the terminal caret blinks.
- **Design brief:** `.impeccable/surfaces/app-page-tsx.md`.

## Member portal (`/account`)

- **Wallet first.** `/account` is the membership wallet: one card per organisation (logo, member number,
  unit, role chips), one row per plan with a status chip, a single sentence on where it stands ("Valid until
  31 Mar 2027 · 20 days left") and only the actions that apply now. Pay is the accent button; Renew is
  primary; Cancel renewal is ghost; Leave is a quiet danger link behind a confirmation.
- **Tabs.** Memberships, Profile, Privacy, Teams, Security. Each membership's page (history, details) sits
  under Memberships.
- **History** reads as a timeline per term: dates and amount, then each change in plain words
  ("Active · Payment received").
- **Irreversible steps** (leaving, erasure) always confirm, say what stays (payments) and what doesn't.
  Approving an erasure asks the manager to type ERASE.
- **Slots.** `components/portal/Slots.tsx` reserves the card (P6) and receipts (P7) spots, so they plug in
  without a layout change.

## Public page editor (Settings → Public page)

- **Two columns** from 1280px: the form on the left, a sticky live preview on the right (inert, rendered by
  the same `PageSections` component as `/o/[slug]`, inside the page's own accent scope). Below that width
  the preview follows the form.
- **Sections** are collapsible rows with a show/hide switch, move up and down buttons and remove; one is
  open at a time. Errors from the server mark the row "Needs attention".
- **Draft and publish.** A sticky bar holds Publish, Save draft, Discard changes and Unpublish, with status
  chips for published, unsaved changes and unpublished draft.
- **Accent check.** Presets plus the custom picker; the line under it gives the button contrast against the
  light page and the label contrast, and warns below 3:1.
- **On the public page** the tagline is the layout's one Unbounded phrase. FAQs use native
  `<details>`, so they work without script.
