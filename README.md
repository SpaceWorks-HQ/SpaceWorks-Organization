# Space Works Organization

Run your organisation's memberships in one place: plans, join forms and approvals, members, renewals, online
and offline payments, GST receipts, ID cards and reports. Self-hostable and open source (AGPL-3.0-or-later).

> **Status:** being rebuilt. See [`docs/plans/2026-10-19-membership-rebuild.md`](docs/plans/2026-10-19-membership-rebuild.md).
> The previous app (Aarannu) is in git history.

## Quick start (development)

Node 22 and Docker:

```bash
npm ci
npm run dev
```
